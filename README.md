# Echoes of the Verdant Star

A Zelda-style 2D action RPG built with Phaser 3 + Vite.

## Setup

```bash
npm install
npm run dev
```

Open `http://localhost:5173`

## Controls

| Key | Action |
|-----|--------|
| WASD / Arrow keys | Move Sage |
| SPACE | Staff attack |
| Q | Cast Aqua Bolt |
| F | Toggle debug overlay |
